Scope: TryBiomod only. The heartbeat requested time was 2026-10-10T09:00:11.904Z; evidence collection and release happened during the later executed session, approximately 18:33-19:15 UTC. This is not a claim that the work ran at the requested time.

## Problem and change

If the initial store-state read failed, Cart and Checkout remained on Loading with no durable recovery action. Both now show the existing generic connection error with Retry cart or Retry checkout. A synchronous lock prevents overlapping retries, and the control is disabled while the read is pending. Retry calls the existing state refresh; it does not clear a cart, create a quote, submit an order or start a payment. Background errors after successful load leave the current cart and checkout form intact.

Affected files: components/store/account.tsx; tests/store-load-recovery-v1.cjs; this log.
Affected URLs: https://trybiomod.com/cart and https://trybiomod.com/checkout.
Hypothesis: shoppers experiencing a transient initial connection failure can recover instead of being stranded. Recovery and downstream checkout completion are the intended measures; no conversion lift is demonstrated by this release.
