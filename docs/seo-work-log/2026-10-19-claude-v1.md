## Why this change

Product pages are now entering Bing's index, but the one that matters most sits behind seven established product pages for "buy bpc-157 10mg". Every competitor page in that set carries several paragraphs about the product; this site's Description tab held one sentence ("Body Protection Compound in a 10 mg vial.") plus a research-use line, and most of each product page's text was shared chrome (header offers, cross-sell cards, the vial index, footer). The product's own facts were on the page but scattered in the spec table and batch panel, and the Product structured data's description was the 160-character meta description.

The competitor audit (docs/competitor-search-audit-v1.md) rules out sequences, molecular weights and storage copy until the owner supplies documentation for the exact sold material, so the added text uses only records the site already publishes.
