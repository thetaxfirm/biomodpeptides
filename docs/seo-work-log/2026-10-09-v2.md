# October 9, 2026: search-engine and AI-assistant discovery v2

Author: Claude. Scope: TryBiomod. Owner direction (Oct 9): improve visibility across search engines and AI assistants. Parent commit: 79844ea.

## Problem

A Claude web search for "trybiomod research peptides" returned no trybiomod.com result, not even for the brand. The robots policy already admits all crawlers (verified with OAI-SearchBot, Claude-SearchBot, PerplexityBot, Bingbot and GPTBot user agents, all HTTP 200). There was no way to notify non-Google engines of new pages and no llms.txt.

## Changes

- IndexNow key file `public/7a2a2775e1f5d580b51600e5e34016f1.txt` and `scripts/indexnow-submit-v1.mjs`. The script reads the live sitemap and submits only those URLs to api.indexnow.org, which shares submissions with Bing, Yandex, Naver, Seznam and Yep. Bing's index also feeds ChatGPT search, Microsoft Copilot, DuckDuckGo and Yahoo. Run it after any deploy that adds or changes public pages.
- `/llms.txt` (llmstxt.org format), generated from `sitemapPaths` and the reviewed `pageInfo` metadata. It returns 404 unless indexing is enabled on the public origin. Held products, private routes and ineligible pages cannot appear. No new product claims.

## Hypothesis and metric

The brand and product URLs become discoverable to Bing-derived engines and AI search sooner. Measure: Bing Webmaster Tools indexed count (needs an owner sign-in, which agents may not create), `site:trybiomod.com` results on Bing, DuckDuckGo and Brave, and referrals from chatgpt.com, perplexity.ai, copilot.microsoft.com and claude.ai once first-party measurement exists. No ranking or AI-answer inclusion is claimed.
