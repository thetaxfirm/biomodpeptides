## Change: product images in the sitemap (committed, NOT deployed)

Problem: product photos render as SVG `<image href>` elements inside `<svg role="img">`, not `<img>`. Image crawlers do not pick those up, so the only signals for product images were og:image and Product.image. The sitemap carried no image entries.

Commit 63fb6e2 on local branch `claude/seo-2026-11-08-v1` (based on origin/main fb93420): `app/sitemap.xml/route.ts` declares the image namespace and gives each of the 20 published product URLs one `<image:image><image:loc>` with `imagePath(p)`, the same file as og:image and Product.image. Non-product pages get none. All 20 image URLs were checked live: 200, `image/webp`, no `X-Robots-Tag`. New `tests/sitemap-images-v1.cjs` (added to the release gate) fails on the old route ("image namespace declared") and passes on the new one; `tests/sitemap-lastmod-v1.cjs` now accepts the optional image element. No visible page changed, so lastmod dates are untouched.
