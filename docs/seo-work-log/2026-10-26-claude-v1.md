## Why this change

Bing indexed `/account/affiliate`, a sign-in page. It already sends `X-Robots-Tag: noindex, nofollow` (proxy.ts, `privatePath`), but robots.txt disallowed `/account`, so Bing could not fetch the page to see the noindex and kept the URL from links and the old `/affiliate-program` redirect. Bing and Google both document that noindex only works on crawlable URLs. The route's own comment ("Crawlable public HTML lets crawlers see the noindex") contradicted its Disallow list.
