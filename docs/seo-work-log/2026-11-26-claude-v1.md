## Change: each news release is linked from the pages it announces (shipped)

A crawl of all 83 sitemap pages counted the internal links pointing at each one. Every product page has 26 or more. The two press releases had one each: the /news list. Earlier logs carried this as an open gap. A page with one inbound link is the weakest signal a site can send about it, and "Biomod Publishes COA Reading Guide" was first seen indexed only yesterday.

What changed:

| Page | Added |
| --- | --- |
| /quality-standard | "From the newsroom" section linking "Biomod Publishes COA Reading Guide" |
| /choosing-a-research-supplier | the same section, same release |
| /faq | "From the newsroom" section linking "Online Store Moves to TryBiomod.com" |
| /news/biomod-online-store-trybiomod | "More news" list linking the COA guide release |
| /news/guide-to-reading-coa | "More news" list linking the store-move release |

The section is built from the release's own link list: a page shows the releases that already link to it, and nothing when there are none. A future release picks up its back-links without another edit. Link text is the release headline with its date. No title, description, price, structured data or existing copy changed. Inbound links: the COA guide release 1 to 4, the store-move release 1 to 3.

The sitemap dates for these five pages moved to November 26; the other 78 stay at November 24.
