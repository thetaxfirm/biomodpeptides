## Reported warning and verified source

The current Google notice identifies noncritical missing `shippingDetails` and `hasMerchantReturnPolicy` fields on Offers, plus missing product `review` and `aggregateRating` fields. The inspected report has four valid affected products and no critical issues. Product URLs identified for post-release validation:

- https://trybiomod.com/product/nad-500mg
- https://trybiomod.com/product/kisspeptin-10mg
- https://trybiomod.com/product/selank
- https://trybiomod.com/product/epitalon-50mg

These are enhancement warnings, not evidence that the pages have been removed from search. Google explicitly permits Product snippets with `offers` alone and may still warn when reviews or ratings are absent. No genuine published product-review dataset was found in the current source, so no review counts, scores, reviewers or testimonials were added.

Actual shipping behavior in `lib/checkout.ts` is free standard shipping at the configured threshold, applied to the merchandise total after discounts and before tax. Below the threshold, checkout can use a live carrier quote or its configured fallback. `lib/easypost.ts` returns the selected carrier rate and service without establishing a universal transit duration. The published shipping policy states a $200 threshold. A narrow read-only production settings verification at 2026-10-10T19:24:56Z confirmed `freeShippingAt=20000` cents and `shippingCents=1500` cents. The $15 fallback is not treated as a universal shipping rate and is not copied into markup.

The published returns policy says research product sales are generally final; damaged, incorrect or missing items should be reported within 48 hours for review. That reporting deadline is not an approved two-day return window, unconditional refund promise or free-return policy.

## Implemented change

- Added Organization-level `MerchantReturnPolicy` using Google's link-only Option B, with stable ID `https://trybiomod.com/returns-refunds#policy` and `merchantReturnLink` pointing to the existing returns page.
- Added Organization-level `ShippingService` with stable ID `https://trybiomod.com/shipping-policy#standard-shipping`. Its single published rate condition applies only to U.S. orders with an order value of at least $200 USD and specifies $0 standard shipping. Description retains the after-discounts, before-tax basis and explains that lower-order shipping is shown before payment. No structured flat rate, handling duration or transit promise is invented.
- Read current store configuration through the existing `config()` function and React request-scoped caching. Only the safe threshold is retained. A failed read, invalid threshold or mismatch with the published $200 policy suppresses the shipping definition and its Offer reference together. No database writes or shipping-setting changes occur.
- Defined the same stable policies on both policy pages and on eligible product pages so their Offer references resolve within each product document. Return references use `hasMerchantReturnPolicy: {"@id": ...}`. Shipping references use `shippingDetails: {"@type": "OfferShippingDetails", "hasShippingService": {"@id": ...}}`, as documented by Google.
- Made only `/shipping-policy` and `/returns-refunds` eligible for indexing and the sitemap. Product publication holds, private routes, previews, filtered-page noindex behavior and existing offer price/availability verification remain unchanged. Existing matched-certificate properties remain intact.

Affected files: `lib/merchant-policies.ts`; `lib/seo.ts`; `lib/seo-policy.ts`; `tests/merchant-policies-v1.cjs`; `tests/brand-discovery-v1.cjs`; this log. No customer-facing policy text, pricing, inventory, checkout rules or payment configuration changed.

Affected URLs: the two policy URLs above and all already-eligible `/product/...` pages. The verified live sitemap now contains 28 URLs, including the same 17 products, compared with the earlier 26 URLs. The verified live llms.txt also lists 28 URLs. Both include the two additional policy URLs; no product publication hold was removed.

## Official documentation supporting the implementation

- [Google merchant listing Offer properties](https://developers.google.com/search/docs/appearance/structured-data/merchant-listing#offer): global merchant policy references and their exact Offer shapes.
- [Google merchant shipping policy](https://developers.google.com/search/docs/appearance/structured-data/shipping-policy?hl=en): Organization `hasShippingService`, shipping conditions and order-value ranges. Transit/handling details are omitted where not established.
- [Google merchant return policy](https://developers.google.com/search/docs/appearance/structured-data/return-policy#structured-data-type-definitions): Option B accepts a customer-facing policy URL without inventing a return category or number of days.
- [Google Product snippet properties](https://developers.google.com/search/docs/appearance/structured-data/product-snippet#product): a valid `offers` property can satisfy Product requirements; missing genuine review/rating data may remain a noncritical warning.

Documentation was checked during this work, not inferred from generic schema examples. Markup does not establish eligibility for every Google shopping feature or guarantee rich-result display.
