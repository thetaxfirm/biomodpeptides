## Evidence and useful increment

The existing public endpoint accepts page views only, and its route map excludes cart and checkout. The October 12 sprint requirement explicitly includes those shopping stages. Without them, page-view counts cannot help locate checkout friction. This release adds six independent aggregate counters: accepted cart addition, visible nonempty cart, checkout sign-in screen, usable checkout form, accepted current delivery quote, and returned payment handoff URL. It does not infer linked journeys, unique visitors, abandonment percentages, conversion rates or paid orders.

Client collection is limited to eligible research-product carts in live checkout, with current catalog/publication checks, readiness, cart error/conflict checks and known-admin exclusion. It shares document-scoped opt-out state with page views and honors GPC, DNT and webdriver exclusions. Only the fixed event string leaves the client; no product, person, order, payment, promo, price, path or referral data is in a stage event. No analytics cookies, persistent identifiers or retry queue were added. A successful cart write counts before a subsequent refresh can fail. Pack delegation counts once; ordinary quantity changes/removals do not count as adds. Delivery/checkout responses are checked against stale context, owner and mount state before measurement. Metrics failures cannot block commerce.

The endpoint retains same-origin, streamed body-limit and strict field validation independently of shopping-session/IP rate-limit storage. Shopping has its own activation timestamp, daily cap and aggregate table. Its report authorizes an administrator before parsing query parameters or accessing configuration/storage. Both aggregate tables share transactional retention and the existing scheduled cleanup. The admin Traffic tab now includes Shopping stages with completed UTC windows and separate partial days. The privacy disclosure describes the added counting. Existing commerce behavior, product availability and publication holds are unchanged.
