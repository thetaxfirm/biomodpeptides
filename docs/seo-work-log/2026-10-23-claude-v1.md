## Why this change

`site:biomodpeptides.com` lists seven old-domain URLs. Five of them (four old guides and the blends category, which ranks #3 for "biomod peptides") plus the /tag/nevada-research-supply/ archive that the October 20 log saw ranking for the brand, still ended in a 404 after the domain move: the old domain 301s them to trybiomod.com, which had no matching route. A 404 at the end of the chain drops whatever those listings carry and tells Bing the content is gone. The same fix class as b0d7d33 and 04ba9ca: exact observed URLs only, each sent to the live indexable page on the same topic, unknown paths still a genuine 404.
