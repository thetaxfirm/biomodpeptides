# TryBiomod promo codes release v1

Date: 2026-10-09. Author: Codex. Scope: TryBiomod only.

## Authorized behavior

Owner requested 10%, 15% and 20% promo codes, explicitly allowed adding the promo to pack savings, and requested discreet presentation. Created BIOMOD10, BIOMOD15 and BIOMOD20. One code per order; percentage applies to merchandise after existing pack and scheduled-sale discounts. No minimum spend, redemption limit, or code expiry is configured. Existing presale/inventory availability gates remain in effect. Shipping and tax are not discounted by the code; existing tax calculation and free-shipping eligibility use the discounted merchandise amount. Browser selection is retained in an HttpOnly, SameSite=Lax cookie (Secure on HTTPS) for up to 30 days. Codes are not listed in storefront promotions or public marketing content.

Cart and authenticated checkout offer a collapsed “Have a promo code?” field. Applied savings and removal are visible to the customer. Checkout quotes bind the code and server-calculated amounts; a code/cart/address change requires a fresh quote. Existing no-promo order fingerprints remain compatible. No account, customer record, catalog availability, or base retail price was changed.

## Files and URLs

- lib/promotions.ts: server-owned code lookup and exact-cent allocation.
- lib/commerce.ts: apply one code after pack pricing; preserve discount breakdown.
- lib/checkout.ts: quote, tax, shipping, stored order and payment calculations bind the selected code.
- app/api/store/[action]/route.ts: validated promo mutation, server cookie and state/cart/delivery/checkout integration.
- components/store/account.tsx, promo-code.tsx, promo-code.module.css: discreet controls, separate savings rows and stale-quote protection.
- tests/promo-checkout-v1.cjs, promo-ui-v1.cjs, promo-http-v1.py: money, API, UI and HTTP regressions.
- Changed public flows: https://trybiomod.com/cart and https://trybiomod.com/checkout. No indexed content or SEO metadata edits in this release.
