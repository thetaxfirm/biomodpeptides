# Softgel marks renamed to RUO; last "peptide" words removed (October 23, 2026, v1)

Author: Claude agent for the owner. Owner instruction, October 23, 2026: remove all words of peptide from trybiomod.com and rename the two softgel marks, choosing among "World's First RUO Softgel", "World's Original Biologic Softgel", "Original Biologic Softgel" and "Original RUO Softgel". The owner asked for a recommendation.

## Recommendation applied

- The Original Peptide Softgel™ is now **The Original RUO Softgel™**.
- World's First Peptide Softgel™ is now **World's First RUO Softgel™**.
- Not chosen: "Biologic". Under U.S. law a biologic is a regulated product class that needs an FDA biologics license, so calling a softgel a biologic invites the same scrutiny the peptide wording did. "RUO" matches the store's research-use-only position.
- Trademark: the filed applications cover the Peptide wording. The new RUO marks are unregistered; ™ is allowed for unregistered marks. Filing the RUO marks, and what to do with the Peptide applications, is for trademark counsel.

## Other visible wording changed

- Compound identities now use the official non-proprietary names: Delta Sleep-Inducing Peptide is Emideltide (DSIP); Copper Tripeptide-1 is Prezatide Copper (GHK-Cu); Epitalon Tetrapeptide is written as its sequence, Ala-Glu-Asp-Gly. Changed consistently in catalog facts, catalog source, COA product facts and the COA reconciliation so the lot matcher still lines up. CAS numbers unchanged.
- /softgels title and description, softgel page heading, softgel product story, About section and sitewide footer note.
- Press release no longer names the former domain in its text.

## Left as is (not visible words)

- Search synonym so a search for "peptide" still finds vials and softgels.
- Old-URL redirects, the internal "research-peptides" category slug, the Worker and database names.
- COA PDF link addresses on the former domain and lab-printed "report to" names inside the original documents.
